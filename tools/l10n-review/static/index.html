Translation review
Runs claude -p on this machine and uses your Claude usage.
File / KeyEnglishTargetStatus

Keys: press ? for the list. o = OK, f = flag, e = edit, a = ask Claude, u = next unreviewed.

Keyboard shortcuts

j / knext / previous row
u / Unext / previous unreviewed row
omark OK and go to the next unreviewed row (again: back to unreviewed)
fflag (from unreviewed or ok) or unflag (from flagged)
e / Eedit the target text / the English source text in place
aask Claude for suggestions
Buttons in the status column: OK (o), Flag (f), Accept (takes the chosen suggestion for Apply).
wmark the selected words as weird
cgo to the comment box
Ctrl/Cmd+Enterin the editor: save and accept
Escin the editor: cancel
